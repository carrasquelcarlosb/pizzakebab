# Pizza Kebab Restaurant Website

## Overview
This project is a modern, responsive website for a Pizza Kebab restaurant, built using Next.js. It provides an interactive menu, cart functionality, and a seamless ordering experience.

## Features
- Interactive menu with categorized items
- Real-time cart updates
- Order placement and tracking
- Responsive design for all devices
- Multi-language support

## Getting Started

### Prerequisites
- Node.js (v14 or later)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/carrasquelcarlosb/pizzakebab.git
   cd pizzakebab
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.
